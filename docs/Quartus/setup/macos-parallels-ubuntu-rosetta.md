# macOS + Parallels + Ubuntu + Rosetta Setup

## Goal

Document the host/guest setup baseline used for Quartus workflows.

## Host Environment

- Host OS: macOS
- Virtualization: Parallels Desktop
- Guest OS: Ubuntu
- Translation layer: Rosetta

## Prerequisites

- Sufficient CPU/RAM allocated to VM
- Shared folders configured
- X11/GUI support verified (if using GUI flow)

## Validation Checklist

- VM boots reliably
- Shared project path is accessible
- Quartus executables resolve in shell
