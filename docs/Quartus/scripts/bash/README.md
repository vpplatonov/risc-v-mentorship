# Bash Scripts

Store runnable shell scripts here.

## Conventions

- Use `.sh` extension
- Add executable bit: `chmod +x <script>.sh`
- Include usage at top of each script

## Files

- `setup_quartus_container.sh`
- `build_sqlite_bridge.sh`
- `start_quartus.sh`
- `check_jtag.sh`
- `run_quartus_compile_example.sh`
